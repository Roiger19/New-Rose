# 🌹 New Rose - Wardrobe con Historia

**New Rose** es una plataforma de e-commerce exclusiva para la venta de ropa usada femenina seleccionada. El proyecto combina una estética sofisticada con una funcionalidad ágil, permitiendo a las usuarias explorar prendas únicas y contactar directamente vía WhatsApp para concretar la compra.

## ✨ Características
- **Diseño de Lujo**: Estética minimalista con detalles en dorado y tipografía premium.
- **Catálogo Dinámico**: Gestión de productos en tiempo real mediante Firebase.
- **Explora por Categoría**: Carrusel moderno para navegar entre vestidos, blusas, pantalones y más.
- **Integración con WhatsApp**: Mensajería automatizada que incluye el nombre y el link del producto de interés.
- **Dashboard Administrativo**: Panel privado para la carga y edición de productos (Cloudinary + Firestore).

## 🛠️ Tecnologías utilizadas
- [Next.js 15](https://nextjs.org/) - Framework de React para el frontend y backend.
- [Tailwind CSS](https://tailwindcss.com/) - Estilizado moderno y responsivo.
- [Firebase](https://firebase.google.com/) - Base de datos (Firestore) y Autenticación.
- [Cloudinary](https://cloudinary.com/) - Almacenamiento y optimización de imágenes.
- [Vercel](https://vercel.com/) - Despliegue y hosting.
